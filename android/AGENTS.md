# AGENTS.md

情绪疏导Agent“心语吧” Android客户端。

## 构建环境须知

AGP 9.2.1 / Kotlin 2.2 需要 JDK 21 工具链。Android Studio 自带 JBR 21 可直接构建；命令行 `gradlew` 需要 `JAVA_HOME` 指向 JDK 21，或按 `gradle.properties` 里注释的写法用 `org.gradle.java.installations.paths` 显式指定路径

## 实现新功能的步骤

**理解需求 → 设计架构 → 编写代码 → 简单测试 → 全面测试**，六步依次进行：

1. **理解需求**：明确功能边界与验收标准，不确定处先使用 `AskUserQuestion` 工具问清。
2. **设计架构**：数据模型、放置的模块、与既有结构的接法。确保可扩展性
3. **编写代码**：按照现有规范和前面的设计编写代码
4. **简单测试**：先通过编译。写简单的测试（或沿用已有的）验证功能是否正常运行。只是改界面样式不涉及功能无需进行此步以及接下来的测试步骤
5. **全面测试**：写全面测试样例覆盖各种可能的用户操作与边界情况，并选择性地跑已有测试确认原有功能不出问题（当前改动可能影响到的所有功能都要跑测试）。不通过就用各种 debug 工具（Layout Inspector、logcat、语义树 dump、断言对比等）定位并修复，直到所有样例通过。测试需要和代码一同进行版本控制和集中管理，请你像写代码一样认真对待它们，并适时地修复测试中存在的问题，补充边界情况以及删除过时的，重复的测试。

## 一些关于修复问题的指引

用户提到功能实现出现问题，如果可能，你先写测试脚本尝试复现，再利用工具排查问题，然后尝试修复并重复上述循环；同时，为了确保修复不带崩已有功能，也要跑已有的相关测试；直到所有测试不出现问题。
